# Quickstart: Flexible Secure SSO Configuration

## Prerequisites
- Existing client and server app running locally
- Access to the dashboard route for admin validation

## Validate the feature
1. Open the app and confirm the sign-in flow can be routed through the configured SSO provider.
2. Update provider settings or mappings and confirm the new rules are applied without requiring a code change.
3. Disable a provider and verify that sign-in is blocked with a clear message.
4. Enable the demo-mode fallback locally and confirm it does not bypass the production access-control rules.
